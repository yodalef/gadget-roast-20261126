A Python program that writes one line roasting the gadget used every day — the smartphone, a planet-spanning supercomputer demoted to flashlight, teeth mirror, and a $1,200 way to ignore people in person — to /output/entry.txt. The line is UTF-8 text of 164 characters, within the bounty's 200-character limit. Deterministic and offline: no network use.

## Run it

```sh
python3 main.py
```

Writes the line to /output/entry.txt (or ./output/entry.txt when /output is not writable).
